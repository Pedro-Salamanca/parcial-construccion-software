## 📌 Descripción del Proyecto
Aplicación de escritorio desarrollada en Java utilizando la librería gráfica **Swing** (`JFrame`, `JLabel`, `JTextField`, `JButton`, `JOptionPane`, `ActionListener`).

Permite realizar de manera intuitiva y sin ambigüedades:
1. **Operaciones Matemáticas:** Suma, Resta, Multiplicación y División (con control estricto de división por cero).
2. **Conversión de Temperatura:** Grados Celsius a Fahrenheit (°C a °F) y viceversa (°F a °C).
3. **Conversión de Moneda:** Dólares a Pesos Colombianos (USD a COP) y viceversa (COP a USD) con tasa fija reglamentaria de $3.200 COP.

---

## 🛠️ Requisitos de Ejecución
- Java JDK 8 o superior instalado.
- Compilación: `javac VentanaPrincipal.java`
- Ejecución: `java VentanaPrincipal`
